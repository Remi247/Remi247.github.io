Installation de votre application

Votre portail s'ouvre
depuis votre téléphone.

Votre installateur a relié votre portail. Il ne reste qu'à installer l'application et saisir le code qu'il vous a remis.

Télécharger l'application

Pour téléphone Android

  1. Téléchargez

    Appuyez sur le bouton ci-dessus. Le fichier arrive dans vos téléchargements.

  2. Ouvrez le fichier

    Appuyez dessus une fois le téléchargement terminé, puis sur « Installer ».

  3. Créez votre compte

    Votre nom, votre email, un mot de passe. Puis saisissez votre code d'accès.

Android va vous poser une question

Un message vous demandera d'autoriser l'installation depuis cette source. C'est normal : cette application vous est fournie directement par votre installateur, elle n'est pas distribuée sur le Play Store.

Acceptez, et l'installation se poursuit.
